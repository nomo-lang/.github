# Support

Nomo is an early development project.

- Use repository issues for reproducible bugs and focused feature requests.
- Use the RFC repository for language, manifest, compatibility, and ecosystem
  design proposals.
- Include the Nomo version, operating system, target triple, command, minimal
  source, and complete diagnostic output in bug reports.
- Do not use public support channels for security-sensitive information; follow
  [SECURITY.md](./SECURITY.md).

Development snapshots may change incompatibly. Before reporting an issue,
confirm whether it still reproduces on the newest published snapshot or
`main`.
